# 🚀 NEXUS-AI-OS

### An AI-Powered Desktop Operating System

NEXUS-AI-OS is an intelligent desktop AI operating system designed to bring productivity, automation, and artificial intelligence together in one platform.

It provides a modern desktop experience with AI-powered assistance, smart file management, productivity tools, and voice interaction.

---

## ✨ Features

- 🤖 **Gemini AI Chat** – Intelligent AI-powered conversations.
- 📝 **Smart Notes** – Create and manage personal notes.
- ✅ **Task Manager** – Organize and manage daily tasks.
- 📅 **Smart Calendar** – Manage schedules and events.
- 📂 **File Intelligence** – Intelligent file management and search.
- 🎙️ **Voice Assistant** – Interact using voice commands.
- 🎨 **Theme Customization** – Personalize the desktop interface.
- 🖼️ **AI Image Generation** – Generate images using AI capabilities.
- 🧠 **AI Agent** – Intelligent assistance for productivity.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/visivisithraa-rgb/NEXUS-AI-OS.git
```

### 2. Navigate to Project

```bash
cd NEXUS-AI-OS
```

### 3. Create Python Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate Environment

Windows:

```bash
.venv\Scripts\activate
```

### 5. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 6. Install Node Dependencies

```bash
npm install
```

---

## 🔑 Environment Configuration

Create a `.env` file in the project root directory.

Add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

**Important:** Never share or upload your actual API key to GitHub.

---

## ▶️ Running the Application

Start the Python backend:

```bash
python app.py
```

Start the Electron desktop application using the start command configured in `package.json`.

---

## 🔒 Security

- API keys are stored in environment variables.
- `.env` files are excluded from GitHub.
- Virtual environments are excluded.
- Node modules are excluded.
- Private user data should not be committed.
